# Roadmap

## Phase 1 (current)

- Read-only window discovery and visible client-area capture.
- Numpy change detection, offline synthetic/replay sources, basic local benchmark.
- Typed model-independent observation, detection, state and simulator action contracts.
- No neural inference and no live inputs.

## Later phases

- Validate mixed-DPI and multi-monitor capture on representative Windows systems.
- Bounded local collector with metadata, near-duplicate and diversity sampling, retention quotas, and YOLO dataset export.
- Local annotation and dataset versioning/splits, uncertain-frame and false-positive/negative review.
- YOLO26n ONNX inference adapter, CPU scheduling, cached detections, optional quantization; training dependencies remain separate.
- Offline simulator feedback loop with deterministic prioritized policies, stale/ambiguous observation safeguards, timeouts, repeated-failure recovery, and outcome validation.

No roadmap item enables live multiplayer control or anti-cheat interference.
